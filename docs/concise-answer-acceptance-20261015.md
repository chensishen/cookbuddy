# 回答格式与精简验收

日期：2026-10-15

## 修改

- 前端采用安全的 DOM 方式显示常用 Markdown：标题、粗体、斜体、行内代码、链接、引用、有序列表、嵌套列表和表格。不将回答作为 HTML 执行，链接仅允许 HTTP/HTTPS。
- 默认生成简洁总结，普通问题优先短答；完整菜谱保留配料用量、工具、操作顺序、温度时间、状态判断和必要条件。逐字原文需明确请求。
- 总结继续经过原文引用及语义、完整性核验。完整菜谱总结两次未通过时，采用逐字核对的精简原文，省去可选工具介绍，保留配方和步骤；这一保守分支会比模型总结更长。
- 修正“没有明显变色，说明……”触发缺失属性审查的误判。真正的原文缺失断言仍需核对全文。

## 结果

- Python 全套含数据库集成测试：340 项通过；前端渲染测试：5 项通过。最后的文案提示及无空格编号兼容修改另通过页面脚本检查与渲染测试。
- 牛奶面包模型总结通过原文审核，正文754字（含引用标记），原文候选4726字，减少约84%。记录：`data/processed/cookbuddy-acceptance/concise-answer-20261015.json`。
- 浏览器复测蒸水蛋简洁回答和完整面包卡片，引用与表格、强调、嵌套列表正确显示。面包复测也覆盖模型总结未通过后，精简原文成功输出的分支。

刷新后历史回答使用新的格式渲染；历史正文不自动重写，新提问使用精简策略。具体长度随问题复杂度与必要条件变化。
