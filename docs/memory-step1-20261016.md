# 记忆改进第一步：任务记忆与模型提取解耦

历史任务记忆由 MemoryService.save_task 根据已完成的执行记录直接保存，不再放在模型提取成功之后。后台顺序为：检查遗忘 epoch → 保存任务记忆 → 提取画像和知识 → 执行维护。

仅保存 completed 且具有 verified / verified_source 证据的任务。沿用原有内容、来源、有效期和 job_id 唯一键，保持重试幂等及遗忘 epoch 防护。

模型提取失败仍进入原有有限重试流程，但已经保存的任务记录不会被撤销，向量同步仍由独立 outbox 处理。画像与知识提取尚未拆成独立任务，这是后续讨论范围。

验证覆盖：模型失败后任务保留、重复处理不增记忆版本及同步任务、旧 epoch 不写入、未完成或未验证结果不写入。包含 PostgreSQL 实际读写测试，不调用远端模型，测试用户数据结束后清理。
