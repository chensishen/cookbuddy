# 真实模型首轮规划诊断（2026-10-20）

本步验证当前配置的 `deepseek-ai/DeepSeek-V4.1-Flash` 能否为经典Agent首轮工具调用提取分类、难度上限，并完整保留用户问题。新增可复跑的小样本评测，保留首轮失败，强化共享提示后复测。完整PRD仍为部分通过。

## 范围与方法

固定题集：`data/evaluation/agent-filter-planning-v1.json`，12道预先写定的开发诊断题，覆盖无约束、分类、难度、组合条件、1/5星边界、否定分类、取消难度限制、过敏条件保留、模糊难度和排除分类。该题集用于本次调试，不能作为独立盲测。

使用生产 `recipe_agent.call_model` 及工具定义，每题只测首轮规划，不执行菜谱工具或答案生成。逐题分别判定参数合法性、过滤条件完全匹配、问题逐字一致；只有三者都符合才计为整题通过。保留原始输出、模型用量、题集哈希及运行前后代码哈希。

串行请求间隔5秒，共享既有准入、冷却、重试和熔断。这个间隔不是账号RPM/TPM配额。若供应商或规划接口失败，停止后续请求，未测题留在总分母内。输出目录禁止覆盖，逐题保存进度。评测脚本：`scripts/evaluate_agent_filters.py`。

## 首轮结果与原因

首轮12次实际HTTP调用均成功，代码在运行期间未变：

| 指标 | 首轮 | 提示强化后复测 |
|---|---|---|
| 参数合法 | 12/12 | 12/12 |
| 过滤条件完全匹配 | 12/12 | 12/12 |
| 问题逐字保留 | 11/12 | 12/12 |
| 三项同时通过 | 11/12 | 12/12 |

失败题原句为“不是难度不超过2星，难度不要限制；蒸水蛋需要哪些原料？”。模型正确省略过滤参数，却把工具中的 `question` 缩写为“蒸水蛋需要哪些原料？”，删掉了用户取消限制的前缀。这是原始工具参数契约失败，不是错误添加2星限制。

既有 `normalize_tool_request` 与统一分派会恢复完整原问题，新增回归验证确认该保护仍有效。本步没有将这层恢复当成模型原始输出通过。

首轮证据：`data/processed/prd-acceptance/agent-filter-planning-20261020-before/report.json`。该失败结果保留不变。

## 针对性改进与复测

将“逐字复制完整问题，保留否定、取消限制、过敏、数量及标点，不得摘要或删前缀；取消的条件不填过滤参数”作为共享提示，加入经典Agent系统提示、工具参数说明及LangChain问答专员提示/工具说明。

同一固定题集的复测记录：`data/processed/prd-acceptance/agent-filter-planning-20261020-after/report.json`。最终指标、实际用量与后端回归日志汇总于 `data/processed/prd-acceptance/agent-filter-planning-20261020/summary.json`。

复测12/12通过，原失败题完整保留取消限制的前缀。两轮各12次HTTP调用，没有额外重试或未知用量；供应商报告总Token分别为11608和12457。两轮题集哈希相同，各轮代码在测量期间均未变化；费用仍未评定。

本轮只实测经典Agent的首轮规划。LangChain的真实工具封装已有本地测试，本步没有运行真实模型驱动的完整LangChain任务。单轮12题的复测不能证明稳定准确率或提示修改的统计收益；后续仍需独立题集、多轮及端到端验证。正式封存的失败报告不被本次开发诊断替换。
