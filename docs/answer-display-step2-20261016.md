# 回答展示第二轮：编号步骤与配图

## 实现

- 在现有答案生成请求中为 claims 增加 kind：直接回答、用料、工具、步骤、关键提醒。没有增加额外的模型排版请求。
- 所有展示文本仍进入原有参数、引用、原文支持和完整性检查；不另生成一份未经校验的展示摘要。旧格式程序回答和历史回答继续兼容。
- 每块保留最初选中的精确引用行号，和事实校验扩展后的完整摘录分开。图片只绑定到明确引用了图片所在行的内容块；不凭“离哪一步近”推断，避免把位于下一步前方的图片放进前一步。歧义绑定不展示，普通步骤每块最多两张图，总计最多八张。
- 材料、工具和提醒分区，操作使用有序列表。原文阶段编号保留；相邻的两个生成块若实际来自同一原文步骤，则合并展示并保留全部动作、条件和图片。
- 同一来源的问答与图片工具结果合并时，已核验的答案及图文绑定优先，避免图片工具的状态或摘要覆盖答案。
- 完整菜谱首次摘要未通过时，直接采用已有的逐字核对原文组织展示。该路径仅省去此前允许省略的工具介绍，所有其他保留文本必须与既有原文组装结果一致；图片按原文行号穿插，不统一堆到末尾，也不受旧前四张图片限制。
- 拓展普通明确菜名的“用料和步骤”请求对该原文回退的使用；替代、库存、过敏、份量调整以及指定子步骤仍保留原问答处理边界。

## 验收结果

- 372项Python测试通过，包含PostgreSQL集成测试；17项前端测试通过。
- 新增覆盖：保留精确图片定位但扩展事实摘录、图在步骤之前、歧义或变更来源不配图、温度无依据仍拒绝、阶段编号不移位、同一原步骤拆分后合并、源文回退不能改字、图片工具与问答合并不丢答案，以及完整面包后部预览图9/10。
- 真实酵头问答：模型生成、支持核对与完整性核对通过。浏览器最终为三个操作步骤，盖布图片紧随第二步，最终形态图片紧随第三步，条件和发酵时间保留。页面端本次11.2秒完成。
- 蒸水蛋：语义复核仍出现误判，没有展示未通过的模型结论，转为逐字核对的原文步骤；CLI本次5.88秒，页面本次9.1秒完成，显示完整五步及用料。原文未写温度单位，未擅自补单位。

## 边界

复核提示已澄清材料表互补、原文未写单位及可选语气等情况，但没有宣称语义复核误判全部消除。原文回退依靠逐字来源检查，可能比模型摘要长；不是让被拒绝的生成结论绕过检查。旧历史中没有结构信息的长段落不自动猜分句，原文完整请求维持原顺序和配图。

图片绑定核对的是作者图注及原文位置，不把图片内容作为温度、熟度或配比的视觉证明。上述少量真实样本也不代表全库效果或普遍耗时保证。
