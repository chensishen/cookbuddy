## 已落实的改进

- **真实 Naive RAG**：同一批 372 份 Markdown 来源，按 cl100k_base 的 512-token 预算连续切原文，得到 954 个无重叠窗口；不使用标题边界、上下文前缀、BM25、补召回和重排。使用同一供应商、同一 Embedding 模型和 1024 维空间，独立保存在 `data/processed/naive-512-v1`，不会发布到活动 Milvus。词元预算内按字符边界切割，保留原文字符和行偏移。跨策略 gold 按原文行范围与窗口交集至少 32 字符映射，短 gold 使用其完整长度；不同粒度的 Recall 分母不同，因此单独报告，不把分块差异解释为纯检索组件收益。
- **向量批次完整性**：检查响应条数、唯一整数编号、维度、有限值及非零向量。实测供应商每批 16 条时编号出现重复，构建已中止并保留失败日志；每批 8 条完成。补充单条重新向量化，三个抽样位置最近的存储向量均对应同一正文。单条与批量输出存在数值波动：首次某项余弦为 0.9892，未通过探索性的 0.999 检查；该失败与重复核对均保留，不能声称供应商完全确定性。
- **引用窗口边界**：基线只能引用实际提供窗口中的唯一连续摘录，程序计算字符、行号并回查原文；不会为了完整行号而泄漏窗口外正文。生产规则引用准确率按 PRD 9.3 检查菜名、章节、路径、范围和逐字摘录，另行报告语义支持评审。
- **来源隔离测试**：32 份未出现在旧开发标注中的来源，共 96 道检索题和 4 道虚构库外题；12 道进行四方案回答对照。参考答案由原文对应章节构造，标注方式公开，不声称由人工认证。封存记录题集哈希、递归脚本哈希、来源交集与执行状态；代码/数据变更和第二次正式执行都会被拒绝。
- **独立评审**：本轮评审使用 `Qwen/Qwen3.5-35B-A3B`，应用生成模型保持 `deepseek-ai/DeepSeek-V4.1-Flash`。独立配置支持同供应商复用密钥、跨供应商单独配置密钥。judge 用固定参考要点索引、矛盾列表和公开规则打分，保留原始结论、规则汇总及冲突；缓存键包含答案、问题、原文、供应商、模型、rubric 与题集版本。
- **Ragas 五项指标**：锁定 0.4.2，实际运行 Faithfulness、Answer Relevancy、Context Precision、Context Recall、Factual Correctness；记录模型、向量模型/维度、逐项失败和适用覆盖。基线采用实际提供的上下文；Closed-book 的上下文精确率/召回率记 N/A，忠实度按明确标注的 gold 来源审计。开放式库存推荐没有唯一参考答案，参考依赖指标记 N/A；不拿模型自身回答充当 reference。低分原样保留。
- **盲评包与导入**：跨三份报告分层抽取 50 条真实答案，隐藏方案编号并打乱次序，附问题、摘录、原文与参考要点。两份空白评审模板要求真实评审标识、独立评审声明、正确性/完整性/引用支持、回答及引用可用性评分、理由。导入拒绝漏评、重复、相同评审、无效评分和答案变更；计算人际及 judge/人类共识 Cohen's κ。恒定评分导致的 κ 不可定义，不用 1.0 替代。本项目暂以 κ≥0.6、至少 40 条共识检查校准，阈值属于实现中的保守暂定值，非 PRD 明文门槛。
- **用量账本**：可选跨进程 JSONL 账本记录真实 HTTP 调用的模型、阶段、用量和失败，包含 Embedding/重排和 Agent；不保存密钥、提示词和向量。没有返回计费用量的调用保持未知，缓存命中不新增调用。评审 SDK 的成本与产品请求分开；没有完整价格、计费用量和产品预算时不伪造总成本。
- **真实稠密重排消融**：A-2 从保存的原始向量通道 Top-20 重新调用重排；A-1 为检索级去重排，A-6 为端到端固定工作流。缺少独立索引或开关的实验在矩阵中明确列出，不用删除同一融合列表中的条目冒充完整消融。

## 完整样本与条件子集的统计口径

首次封存检索集含 32 个来源、每源 3 题，共 96 道有 gold 的查询。同源问题存在相关性；补充分析按来源簇进行 bootstrap 与配对符号置换。完整系统相对 512-token 基线的 Hit@5 从 42.7083% 到 98.9583%，绝对增量 56.25 个百分点，相对增量 131.71%；来源簇 bootstrap 的增量区间为 [42.7083, 70.8333] 个百分点。此结论只描述本次模板样本和公开的跨粒度 gold 映射，见 `source-cluster-comparison.json`。

重排同时保留两种结果：`rerank_significance` 是实际成功调用子集，58/96 题，可能受调用成功条件影响；`rerank_policy_effect` 是开启可降级策略与关闭重排的完整 96 题配对，包含所有降级及失败零分，按来源簇置换。完整策略 MRR 增量 0.181076，p≈0.0001；真实模型调用仍为 58/96，不改写为 100%。门槛改为判断“策略效果显著且查询样本覆盖完整”，实际模型覆盖率单列。两种分析均保留，不选择成功调用子集充当完整系统效果。
