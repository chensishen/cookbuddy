# 本地应用五场景验收

日期：2026-10-12。本批从问答脚本转到实际应用入口，按固定场景检查原文、图片、外链、直接 RAG 与 Agent 选工具。分别在两个终端运行：

```sh
python3 scripts/serve_recipe_app.py
python3 scripts/smoke_recipe_app.py
```

第二条命令通过本地网页接口依次提交五个请求、等待任务结束，并核对工具状态、逐字原文摘录和本地图片文件。详细结果与每次执行记录路径见 [`summary.json`](../data/evaluation/app-acceptance-v1/summary.json)。这组场景是助手选择的功能验收，不是用户核定的独立准确率测试集。

| 场景 | 本次结果 | 核对重点 |
|---|---|---|
| 蒸水蛋操作原文 | 通过 | 返回完整操作章节，摘录与原文件逐字一致 |
| 基础牛奶面包酵头图片 | 通过 | 返回三张本地原图，路径存在，图注来源一致 |
| 完美水煮蛋图片 | 按预期提示不足 | 没有本地原图；原文的一处外部图片链接单列为“未下载、内容未核验” |
| 酸辣土豆丝调料问答 | 通过 | 真实走 Embedding、Milvus、重排和来源回答；两段摘录逐字匹配 |
| Agent 查看酵头图片 | 通过 | Qwen3-8B 选择图片工具，返回三张本地原图及来源 |

同时修复了图片工具的两个展示问题：原文外链此前在页面中完全不可见；按章节或关键词筛选图片时，外链此前仍可能不受筛选条件约束。现在外链只作为原文链接列出，不把其内容当成已核验图片或配方事实；页面只打开 `https` 外链。执行记录的 Markdown 预览也保留“未下载、内容未核验”标记。

另外用真实浏览器打开页面，提交完美水煮蛋和酵头图片两种查询：页面分别显示外链状态与三张图片；三张图片的浏览器加载状态均成功。浏览器曾报告一次图标文件 404，不影响本批查询功能，未把它算作验收失败。

项目现有 **176 项测试通过**。本批没有扩大结构化候选启用范围，也未解决自由生成的资料充分性误判或历史接口超时。下一阶段可把用户实际提出的查询作为独立验收题，按检索、重排、依据和回答四层记录错误；这比继续增加开发题特例更能反映真实使用质量。
