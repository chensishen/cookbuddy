# 短期与长期记忆调整（2026-10-23）

## 规则

- 现有食材：仅保存于当前会话槽位。可以追问“我有什么食材？”、按现有食材选菜；新的库存声明替换本会话库存。新对话不继承，未提供库存时重新询问。即使用户说“记住”，模型或工具也不能把 inventory 写入长期画像。
- 稳定口味、忌口：跨会话保存。明确声明立即生效，不必额外说“记住”。选菜过程中声明辣度或忌口，更新画像并继续当前任务。
- 修改口味：例如“我的口味改成重口味了”，会替换旧的清淡偏好并保留版本链；少油等兼容偏好保留。“不再喜欢某口味”记录负向口味偏好，不误记为食材忌口。统一“重口味”等常见名称，防止规则与模型重复写入。
- 当餐口味：“今天想吃清淡”仅覆盖当前会话，不改写长期重口偏好。
- 放宽硬性忌口、过敏等限制仍需明确确认；旧任务不能恢复已更新的偏好。
- 历史库存原始记录保留供导出核对，但从长期画像、普通记忆列表与推荐上下文中排除，不转移到其他会话。
