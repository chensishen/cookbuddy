# 经看图核对的文字用于图片查找

2026-10-12。本批接续[六张图片OCR试验](media-ocr-pilot-v1.md)，完成少量人工看图核对、图片查询接入与本地应用展示。核对人是助手；用户尚未逐项复核。核对记录在 `data/processed/media_ocr_pilot/reviewed-text.json`，与原图 SHA-256 绑定。

六张试验图的41个OCR区域中，仅3条短文字用于找图：“玉米油”“牛奶”（戚风蛋糕手写图中的可见名称）、“提前预热好烤箱”（戚风蛋糕烤箱图的字幕）。手写数量与行列、硅油纸包装文案、温度计刻度、草莓酱罐身刻度都没有启用。两张无OCR文字的照片继续仅通过原文图注查找。

现在可以在“查看菜谱图片”模式下填写菜名“戚风蛋糕”和图片关键词“玉米油”，返回手写配方原图；关键词“150”不会因温度计或手写数字而命中。结果同时展示菜谱中的原文图片引用行和单独标注的“图中可见文字（仅用于找图）”。前者是Markdown来源，后者是助手从图中核对的文字，不能互相替代。普通RAG回答、Milvus集合、Embedding和重排均未使用这些图中文字。

实现中，核对文字必须逐字存在于该图片的OCR候选、类型属于手写名称或图片字幕、且不含数字；图片与菜谱来源改变时拒绝旧结果。包装和刻度仍在原始OCR记录中供研究，但不参与正式图片查找。新的图片关键词查找是有限的字面包含匹配，只覆盖这3条已核对文字，不能据此推断全库多模态检索效果。

复现：

```sh
python3 scripts/recipe_agent.py '查看戚风蛋糕里写着玉米油的图片' --mode images --title 戚风蛋糕 --section 玉米油
python3 -m unittest discover -s tests
```

本批真实本地工具调用返回1张戚风蛋糕配方图，来源行与图片哈希通过检查；项目164项测试通过。若以后要让图片中的配方数值参与问答，需要另做逐格名称—数量—单位核对及冲突处理，而不是放宽本批“找图专用”的标记。
