## 回答质量与延迟

| 方案 | 正常返回 | judge 正确且完整 | Ragas 忠实度均值 | P50 / P95（秒） |
|---|---|---|---|---|
| 闭卷 | 5/5 | 4/5 | 0.389 | 1.69 / 2.05 |
| Naive RAG | 5/5 | 5/5 | 0.863 | 1.59 / 4.17 |
| 完整 Agent | 5/5 | 5/5 | 0.852 | 7.97 / 19.51 |

Ragas 每方案只评分 3 道库内题，不包含两道库外拒答。judge 与生成使用相同模型，尚无人评校准；其通过比例不能当作独立答案准确率认证。

完整 Agent 逐题耗时：温度时间 7.97 秒、番茄炒蛋原料 19.51 秒、库存推荐 3.47 秒、库外题分别 13.42 秒和 7.02 秒。其样本 P95 比 Naive RAG 高 15.34 秒，超过 PRD 的交互 P95 增量 1.5 秒建议预算；5 题样本不足以估计生产 SLA。本轮没有测首 token 延迟。

三个库内完整 Agent 回答的 6 条引用均逐字核对通过。这证明本批溯源一致，不等同于全库引用准确率达到 98%。

## 仍未达标的原因

1. **库存推荐存在评审分歧。** 完整 Agent 的温度、原料题 Ragas 均为 1.0，库存题为 0.556，拉低均值至 0.852；judge 却判库存题正确且完整。该回答是工具按原料表计算的覆盖率，并非自由生成；Ragas 上下文已包含原料表、用户库存和派生数据，仍不足以仅凭总分判断究竟是哪条事实或评审环节有问题。其声明拆分与逐项支持结果未在现有报告中保留，需要针对该题人工校准，不能直接认定为模型幻觉或误判。
2. **重排稳定性和收益仍不足。** `amount` 题远程重排超时，回退原排序；`unknown` 题因本地准入预算耗尽而降级。运行事件另有一次重排准入超时，发生在完整调用链中。8 道相关性题中只有 7 道实际重排，配对结果不显著；端到端指标保留降级结果，没有只挑成功重排。
3. **完整 Agent 的开销尚未证明合理。** 本题集 Naive RAG 与完整 Agent 的 judge 通过比例相同，后者更慢，忠实度均值也没有更高。已记录生成调用 token 总数分别为 13,364 与 26,081；这不是包含 Embedding、重排、评审和失败请求的总账，不能直接换算为完整成本。
4. **原有工程与验收缺口没有因换模型消失。** 活动元数据和通用难度过滤、新 IR 发布、固定 512-token 基线、完整消融、独立 dev/test、人工校准仍待完成。现有价格快照与本轮供应商/模型不匹配，成本仍留空。Ragas 本轮仅完成忠实度，其他指标未覆盖。

本轮已经解除上一轮回答评测无法完整执行的阻塞；下一步应聚焦库存题的逐项评审校准及 Agent 调用链延迟，而不是仅重复运行同一小题集。
