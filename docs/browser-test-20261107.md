## 2026-11-09 长期偏好回归

- 现象：新浏览器会话读取长期偏好返回“目前没有已保存的饮食偏好”，与旧记录中的微辣偏好不一致。
- 定位：`playwright-cli list` 显示测试浏览器使用 `user-data-dir: <in-memory>`。浏览器会话重建后会生成新的签名 Cookie 和用户身份；旧微辣偏好属于另一个身份，当前身份确实没有长期偏好。
- 处理：浏览器测试改用 `--persistent --profile /Users/admin/.cookbuddy-playwright/profile`，保留同一签名 Cookie 和用户身份。没有按偏好值跨账号迁移或合并数据。
