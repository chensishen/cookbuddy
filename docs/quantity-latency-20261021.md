# 原配方用量查询延迟改进（2026-10-21）

当前无附加限制的单菜原配方用量查询可直接交付已核对的原料表及“计算”章节，不再必须调用远端检索、重排、生成与复核。仅整理原文，不补数字、不统一范围、不替用户换算；保留份量、公式、可选食材与工具。
