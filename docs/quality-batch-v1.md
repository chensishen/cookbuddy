# 新问题问答质量验收

日期：2026-10-13。环境：conda `py3.12.11`。本批聚焦数量单位、缺料、否定条件、原文差异、同名菜谱以及原文与图片复合请求。使用当前正式知识库 `bounded_v3` / `recipe_bounded_v3`，没有修改原文或重新入库。

## 验收方法

先从原文制定八个问题及预期，见[固定题集](../data/evaluation/quality-batch-v1.json)。这是开发验收样本，其中部分边界与旧测试相似；不能当作盲测、模型排行榜或全库正确率。

[运行脚本](../scripts/evaluate_quality_batch.py)顺序调用现有入口，每题180秒预算；默认关闭答案缓存。每题保存完整工具结果、模型与阶段路径、知识库版本、预期来源全文哈希。每轮单独目录，存在的记录不覆盖。

评估分为两层：程序核对引用路径、起止行号和逐字摘录；助手随后逐题对照原文审阅回答、条件和工具范围。人工审阅记录与原始模型输出分开保存。空引用不算精确引用通过；同名澄清与不存在菜谱的拒答按各自行为验收，不要求凭空添加证据。

## 复现

```sh
conda activate py3.12.11
python scripts/evaluate_quality_batch.py --round first
# 新轮次保留首轮结果；可只选择需要复查的题目。
python scripts/evaluate_quality_batch.py --round followup --ids q04 q05
python -m unittest discover -s tests -q
```

真实问答会调用已配置的Embedding、Rerank及生成接口，消耗额度。语义审阅不是重新运行脚本自动产生的“正确率”，应查看单题原文和输出再记录。

## 本批结果

首轮八题：六题满足各自预期；草莓酱回答把减糖建议升级为禁令；蒸水蛋章节差异题被核对程序误拒答。见[逐题审阅](../data/processed/quality-batch-v1/review.json)，原始记录按`first`、`followup`、`repaired`、`final`保存。

| 问题 | 最终结果 | 实际路径 |
|---|---|---|
| 糖醋汁五种用量与单位 | 通过，50ml／40ml／30g／20ml／10ml | 模型生成 |
| 美式炒蛋缺牛奶／奶油 | 通过，不给替代品 | 原料表比较规则 |
| 番茄丁、培根丁是否必备 | 通过，保留可选属性 | 模型生成 |
| 草莓酱零糖方案 | 安全降级，仅展示原文；没有生成可用结论 | 模型连续失败后原文工具 |
| 蒸水蛋热水／温水章节差异 | 通过，保留260ml、1.5倍、20~30与未注明单位 | 有限来源对照规则 |
| 陈皮排骨汤同名 | 通过，两个来源待选择 | 工具澄清 |
| 草莓酱操作原文＋图片 | 通过，两种来源工具、四张本地图片、不调用RAG | 单Agent选择工具 |
| 不存在的菜谱原文 | 通过，拒绝伪造来源 | 原文工具 |

因此是**七题完成预期，一题降级**，不是八题问答全通过。所有返回的实际原文摘录逐字核验通过；同名澄清和不存在菜谱的拒答没有引用，不纳入摘录通过率。

## 改动及证据

1. 生成与复核提示要求保留建议语气，明确“原文未给方案”不等于“做法不可能”。真实补测表明只改提示不足，草莓酱仍生成同一过强结论，记录保留。
2. 对“不能完全不放／不能省略／禁止替代”等明确禁令增加保守的程序检查，引用无对应明确限制时拒绝发布，再走已有一次修正。这是有限措辞防线，不是通用语义证明器；最终仍需语义核验。
3. 生成两次校验失败且能唯一定位菜谱时，使用已校验的原文工具提供逐字来源，标为`degraded`／`partial`，不展示被拒绝的生成结论。草莓酱最终真实补测返回五段原文，含400克及可考虑200g建议；不判断零糖变更是否可行。
4. 全文缺失属性审核区分“某章节未说明”和“全文未说明”。混合回答的缺失断言通过后，数值／做法仍单独核对引用，不能借缺失审核绕过正面事实检查。
5. 有限章节对照可接受问题提及原文已有数字；要求明确问原文或章节，不接纳新温度／时长。蒸水蛋最终走已绑定源哈希的对照规则，而非宣称模型生成已改善。

[最终两题补测](../data/processed/quality-batch-v1/final/)：草莓酱33.616秒降级；蒸水蛋0.536秒规则回答。首轮可选配料生成102.752秒，说明正常模型问答延迟仍需后续独立优化；以上单次耗时不能代表P95或生产容量。

最终**234项测试通过**，见[测试记录](../data/processed/quality-batch-v1/unit-tests.json)。新增测试验证摘录篡改、错误行号／路径、空引用、限制强度、正面事实不会绕过核验、原文数字与新数字的边界、生成失败后的精确来源降级。当前批次到此收口；仍保留草莓酱无法稳定生成合适结论这一已知限制，不继续增加菜谱专用答案去掩盖它。
