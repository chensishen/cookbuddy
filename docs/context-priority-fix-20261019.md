# 多轮选菜条件与记忆优先级修复

日期：2026-10-19。范围：浏览器回归中的后续排除辣椒、明确不辣与旧辣味偏好冲突。

## 原因与修改

- 状态归约器已经在新增辣椒排除条件时清除了辣味，但 MemoryRuntime 随后向空口味槽位重新注入长期或会话中的辣度偏好。现在继承的微辣/辣味偏好不能覆盖辣椒排除条件；兼容的“不辣”仍可继承。长期偏好记录不因此改写，过敏等硬约束仍由原代码强制执行。
- `推荐3道鸡肉菜`、`推荐3道不辣的鸡肉菜`等完整表达此前残留未知条件。新增有界语法，把食材、口味和数量分开解析；不识别的“低脂”等条件仍保留，不静默丢弃。
- 原先不辣推荐必须在简介中找到“不辣”字样。现在依据完整原文配方、步骤及加辣说明筛选，保守排除辣椒、胡椒、芥末等加辣用料与成分不明的调料，返回有原文依据的候选，不通过删改原配方满足要求。这是基于知识库文本的候选筛选，不是对实际制作辛辣程度的保证；微辣筛选保持原有要求。

改动文件：`scripts/cookbuddy/ltm/runtime.py`、`scripts/cookbuddy/recommendation_turn.py`、`scripts/preference_recommendation.py`。
