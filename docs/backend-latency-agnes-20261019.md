# 后端耗时优化及 Agnes 模型切换验收

日期：2026-10-19。

## 已完成

- 根据我的喜欢/偏好/口味推荐识别为结构化推荐任务；使用已保存偏好直接筛选及个性化排序，避免把该表达当成未知筛选条件而进入完整RAG。兼容迁移同类旧任务条件，其他未知条件仍保留。
- 意图语义检索共用6秒预算；样例向量缓存24小时，键含向量空间、Intent版本和样例内容摘要，动态扩展仍会失效更新；超时遵循现有置信度门槛并记录降级，父任务取消仍生效。
- API准入、重试、退避共用一次调用预算，嵌套调用继承父任务取消。JSON截断修复也共用40秒预算。
- balanced问答中重排接口8秒、重排子进程最多12秒；接口超时保留已核验检索候选的原顺序，并标注排序降级。原文校验没有放宽；错误格式不作可信重排结果。
- 生成、修复和复核共用最多40秒；保留已有原文降级预留时间及父请求deadline，serial评测配置不更改子进程阶段预算。
- 指定菜谱的烘烤温度＋时间问题增加狭义原文事实路径：仅唯一明确操作步骤，保留相邻原文调整提醒。不会解释省略、替代、比较或改用设备；遵守硬限制来源过滤。避免重复生成并让模型复核已经明确的同一句原文。

## 模型配置

聊天生成、复核、意图分类、Agent及记忆模块统一通过现有独立LLM配置读取agnes-3.0-flash，地址https://apihub.agnes-ai.com/v1；Embedding与向量库没有变更。Agnes使用其文档中的chat_template_kwargs.enable_thinking=false，移除其他供应商的思考字段。官方协议参考：https://agnes-ai.com/zh-Hans/docs/agnes-30-flash。

密钥仅在被Git忽略的本地.env中，文件权限0600；示例配置无密钥。页面模型名称从/api/status加载，项目服务已经重启。

## 验收结果

- 后端全量490项测试通过（包含PostgreSQL＋Milvus集成），43.375秒；前端25项通过。
