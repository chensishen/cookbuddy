# 普通做法问答长等待修复

日期：2026-10-19。范围：普通单菜做法、用量与步骤，以及菜单中指定序号的做法追问。

## 原因与修改

完整菜谱原文已经存在时，原链路仍进行向量检索、重排、模型生成与复核。现有原文整理备用分支仅在生成内容校验失败后执行；模型等待超出子进程预算时，进程先被终止，无法使用该备用回答。先前浏览器回归中的普通做法请求因此等待约43–48秒后只显示降级提示。

现在对整句可以识别的、不修改配方的做法请求，直接复用原文整理与统一引用校验器：

- 核对唯一菜谱来源、当前文件和知识库章节版本；引用与行号逐字核对，保留用量、操作及条件，继续使用已有图文展示组件。
- 菜名别名与既有检索共用规范化规则，例如番茄炒蛋对应西红柿炒鸡蛋。
- 管线在模型意图识别前处理这类明确请求；套餐序号追问绑定会话选中的原文来源。工具入口同样支持，避免重新进入远程检索与生成。
- 完整消费问题中的剩余文字。替代、减量、低卡、未知要求、多菜比较或组合图片请求不进入此路径，仍交给现有问答处理。硬约束检查保留。

主要改动：`scripts/recipe_fact_answer.py`、`scripts/retrieval_candidates.py`、`scripts/recipe_tools.py`、`scripts/cookbuddy/pipeline.py`。
