# 回答展示第一轮改进

本轮落实前次审查中的排版和滚动，保持回答文字、原文顺序及来源检查机制。

## 已调整

- 卡片菜名使用二级标题、23px；章节使用三级标题、17px。正文和列表统一为16px、1.8倍行高，阅读区最大720px。
- 调整列表、段落、引用块的间距，取消中文大段斜体的视觉效果，保留强调语义及原文字词。辅助说明颜色加深，减少动态效果偏好下关闭脉冲和侧栏过渡。
- 首次打开历史定位最近一轮问题及回答开头；同一页面内切换对话后，按阅读段落及相对位置恢复，而非强制滚到底部。刷新页面后不会跨会话持久恢复阅读位置。
- 新回答完成时，仅在用户仍位于当前轮开头附近时对齐该轮，向上查看历史时不会强制拉回新回答。
- 图片保留固定比例和高度上限；加载提示覆盖在占位区上，加载成功隐藏提示不会额外挤压正文。图片保持完整比例显示。
