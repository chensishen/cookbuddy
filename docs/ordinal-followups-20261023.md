# 推荐序号追问与定点换菜修复（2026-10-23）

## 问题与原因

用户反馈：推荐两道菜后，连续查看第一道和第二道失败；截图中“换第一道，不要刚才第二道。”“换第一道菜”被要求澄清。

读取对应时段的实际任务记录后确认：截图所在会话的“第二道怎么做？请给我用料和完整步骤。”当时成功对应了炒滑蛋，后续两次换菜进入 clarify。该会话不能证明用户描述的所有步骤均失败，因此另用连续对话回归复现查看步骤的问题。

新增回归首次运行：4 项测试中出现 7 个失败子场景。具体原因：

- “第二道的步骤”“第二道呢”等表达不在序号查看语法内。
- 按菜名查看推荐中的某道菜时，会被当作任务边界，清除推荐列表。
- 换菜语法不支持“换第一道菜”，且食材推荐快捷路径可能绕过换菜排除条件。

## 修复行为

- 查看已推荐菜谱时保留原列表顺序，并单独记录当前查看的菜谱。
- 支持序号步骤追问与省略式追问，序号始终对应当前推荐列表。
- “换第 N 道菜”只更新指定位置；其余菜品和序号保留，换菜候选排除当前列表中的菜。
- 有换菜排除条件时使用支持排除的推荐路径；回答明确说明换了第几道。
- 无法对应的序号继续澄清，保留原状态；明确换话题仍关闭旧列表。
