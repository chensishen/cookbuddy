# 受控矩阵完整复验协议（2026-10-21，复验前确定）

先前 run-v2 的96条及4条执行失败保持原样。为补齐可用对照，对相同6题、相同E0–E8/A-1–A-6及生产参照重新执行完整96条，不只挑失败题重跑，不把复验冒充新盲测。

索引、查询文本、候选数30、最终K=5、生成器、约束提取和原文证据校验均沿用受控协议。唯一执行预算变化：受控matrix_rerank调用从30秒改为90秒，涵盖共享限流队列等待与HTTP读取，外层请求仍180秒。此变更仅在独立wrapper中安装，不修改生产的12秒阶段预算或0.5秒准入策略，不增加本地RPM/TPM、不重置RuntimeStore。受控矩阵时延从来不用于生产SLA，本次也不与旧30秒实验作性能优劣结论。

独立wrapper源码和哈希在首个请求前保存；核心scripts源码运行前后指纹一并记录。若仍有失败，保留固定分母与异常，不再次自动调整预算。先完成生产层生成，再开始本次复验，以减少实验之间的请求竞争。两套报告分别保留，不覆盖。

所有可评回答使用同一独立Qwen judge与rubric；仅当题集哈希、case/variant及完整result均与旧报告一致时携带原评审，评审程序仍重新核对审计哈希，不匹配就真实调用。原生成失败不能复用评审。Ragas五项正式证据仍采用新封存v3四方案的32条/144项，本开发复验不宣称增加Ragas覆盖。原run-v2的核心Ragas也原样保留，不能移植给变化的回答。

完整执行、可评回答评分覆盖、执行成功和回答质量分开报告。完整消融实验的完成不等于每个组件都提高质量，也不意味着全库或生产SLA认证。最终人工校准和预算可接受性须继续保持未定，除非出现真实输入。
