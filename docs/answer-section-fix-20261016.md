## 修改

- 对明确指定“菜名的某阶段怎么制作”的无附加条件问题，预先准备该阶段的连续原文和同名用料组。仅在生成校验失败后使用这一精确原文回退，不展示整篇菜谱。目标阶段不包含后续独立的排错、永久保存等扩展话题。
- 该回退要求明确菜名、唯一阶段匹配、完整同源上下文；调整用量、替代、诊断等问题不走此分支。最终内容、引用范围及展示原文仍由现有校验器逐字核对。
- 后端不再为 degraded / validation_failed / insufficient / tool_failed 结果关联图片；前端也不展示这些状态遗留在历史记录里的图片。
- 行号校验报错包含资料编号、允许范围及实际范围，使修正请求能够定位问题。生成提示明确限制到用户所问阶段，避免无请求地展开排错及长期保存。
